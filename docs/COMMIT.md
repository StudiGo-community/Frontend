# 📝 Commit Convention

> [Conventional Commits](https://www.conventionalcommits.org/) 기반의 커밋 컨벤션을 따릅니다.

---

## 커밋 메시지 형식

```
<타입>: <커밋 제목>(#이슈 번호)

- 무엇을 변경했는지 또는 왜 변경했는지 설명
```

---

## 커밋 타입

| 타입       | 설명                               | 예시                               |
| :--------- | :--------------------------------- | :--------------------------------- |
| `feat`     | 새로운 기능 추가                   | `feat: 메인 페이지 구현 (#5)`      |
| `fix`      | 버그 수정                          | `fix: 로그인 오류 해결 (#12)`      |
| `refactor` | 리팩토링                           | `refactor: 쿼리 훅 분리 (#8)`      |
| `design`   | CSS 및 사용자 UI 디자인 변경       | `design: 버튼 스타일 수정 (#3)`    |
| `style`    | 코드 포맷팅, 세미콜론 누락 등      | `style: 린트 에러 수정 (#1)`       |
| `test`     | 테스트 코드 추가 및 수정           | `test: 유닛 테스트 추가 (#15)`     |
| `chore`    | 기타 변경사항 (빌드, 패키지 등)    | `chore: 라이브러리 추가 (#4)`      |
| `init`     | 프로젝트 초기 생성                 | `init: 프로젝트 초기 세팅`         |
| `rename`   | 파일 혹은 폴더명 수정 또는 이동    | `rename: api 폴더 이동 (#2)`       |
| `remove`   | 파일을 삭제하는 작업만 수행한 경우 | `remove: 미사용 파일 삭제 (#6)`    |
| `type`     | 타입 정의                          | `type: User 인터페이스 추가 (#21)` |

---

## 커밋 메시지 작성 예시

### 단일 변경사항

```
feat: 로그인 기능 구현(#12)
```

### 상세 설명이 필요한 경우

```
feat: 다크 모드 구현(#17)

- 시스템 설정에 따라 초기 테마를 설정하는 기능 추가
- 사용자가 테마를 수동으로 변경할 수 있는 토글 버튼 구현
```

---

## 주의사항

> - 커밋 제목은 **50자 이내**, **소문자**로 작성
> - 제목과 본문 사이에 **빈 줄** 추가
> - 본문에는 **무엇을**, **왜** 변경했는지 작성
> - 이슈 번호 **필수** 포함 `(#이슈번호)`
